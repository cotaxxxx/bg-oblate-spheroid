# Muse 単発監査依頼：D5 外側境界の面 B′ v2 — chat 独立 verifier

2026-11-07 / 依頼: chat / 判定者: Judge

## 0. 依頼内容

新規コード `chat_bprime_iv.py` が、下記の定理の**厳密な下界**を正しく計算しているかを監査してください。成果物は判定（PASS / FAIL）と、FAIL の場合はその箇所と理由です。修正版のコードは不要です（作るのは Dig、chat と Muse は監査）。

**定理（面の下界）：** τ ∈ [0, 1]、λ ∈ [2/5, 33/50] の外箱すべてで H(L_λQ(τ)) ≥ m_∂ ＝ 1/5（Judge 裁定）。

同梱の `chat_m22iv.py`・`chat_m40iv.py` は Muse 監査済み（SHA は §4）。区間演算 I と Taylor 係数 J はそこからの流用で、本件では**新しい部分だけ**を見てください。

## 1. 数式（同梱の仕様 v1 §1 と v2 差分 §1）

- H ＝ (1/π)∫₀^π∫₀^π f·sin ψ dψ dθ、接触点 Q ＝ (a, 0, b) 中心の極座標 ξ ＝ Q cos ψ ＋ (e₁ cos θ ＋ e₂ sin θ) sin ψ、e₁ ＝ (−b, 0, a)、e₂ ＝ (0, 1, 0)。
- r ＝ tan(ψ/4)、s ＝ tan(θ/2)。θ ∈ [π/2, π] は cos θ の符号反転（eps ＝ −1）。
- σ ＝ 4r/(1+r²)、ν ＝ −sin(ψ/2)Q ＋ cos(ψ/2)e(θ)、ξ_z ＝ b cos ψ ＋ a cos θ sin ψ。
- K ＝ ν_x² ＋ ν_y² ＋ λ²ν_z²（コードでは 1 − ν_z²(1−λ²)）、n ＝ ν_y²/K、w ＝ √(λ² ＋ (1−λ²)ξ_z²)、γ ＝ λσ/(2w√K)。
- f ＝ (γ/(2K))[αR(γ) − γβR′(γ)]、α ＝ 1 − n − 2n(1−2K)²、β ＝ n(1−2K)²。
- R^(m)(γ) ＝ 2(−1)^m m!(1+γ)^−(m+1) K_{m+1}(q)、q ＝ (1−γ)/(1+γ)、K_n(q) ＝ ∫₀¹(1−t²)^(n−1)(1+qt²)^−n dt。

## 2. 監査してほしい点

1. **式との対応：** `g_coeff` が §1 とヤコビアン sin ψ·4/(1+r²)·2/(1+s²) を正しく実装しているか。y についての対称性で θ ∈ [0, π] に限ってよいこと、枝 eps ＝ ±1 で θ ∈ [0, π] を過不足なく覆うこと。
2. **K_n の包囲（新規）：** p ＝ 1 − q とした級数 (1+qt²)^−n ＝ (1+t²)^−n Σ_k C(n+k−1, k)(pt²/(1+t²))^k、その項の積分 M(n, k) ＝ ∫₀^{π/4} cos^(n−1)(2θ) sin^(2k)θ dθ の Wallis 式による厳密値（π は区間）、Horner 評価、剰余の上界（t²/(1+t²) ≤ 1/2 による比 ≤ (n+k)/(k+1)·p/2）。項数 N の選択は float で行うが、使う剰余は選んだ N に対して厳密に計算している。q 区間 → p 区間の外向き丸め（2^−48 の格子）と、K_n が q について減少することによる端点評価。
3. **R∘γ の Taylor 係数：** γ ＝ γ₀ ＋ D（D は冪零部分、D³ ＝ 0）として R(γ₀) ＋ R′(γ₀)D ＋ R″(γ₀)D²/2 で合成している。γ₀ はセル（または点）上の区間で、R^(m) をその区間全体で包んでいる。
4. **切り詰め（cap0）の正当性：** K ∈ [λ_lo², 1]、n ∈ [0, 1]、w ∈ [λ_lo, 1]、γ ∈ [0, 1]、sin(ψ/2)・cos(ψ/2)・sin θ ∈ [0, 1]。特に γ ≤ 1 の幾何的根拠。
5. **中点線版の中点則：** セル C ＝ [r_a, r_b]×[s_a, s_b] で ∫∫g ≥ |C|[g(m) ＋ h_r²/24·inf_C g_rr ＋ h_s²/24·inf_{r＝m_r} g_ss]（r で先に積分し、次に s）。`box_lower` の係数と、評価する区間（g_rr はセル全体、g_ss は r ＝ m_r の線）が合っているか。
6. **前因子と判定：** 1/π を 33215/104348 ≤ 1/π ≤ 33102/103993 で挟み、符号を見て掛ける。`check_cover` が τ ∈ [0, 1]・λ ∈ [2/5, 33/50] の直積格子の隙間・重なりを検出すること。
7. **外箱の区間 τ、λ** がすべての量に区間として入っていること（点に縮めた評価になっていないこと）。

## 3. chat が行った確認（参考。監査の代わりにはならない）

- `t_point.py`：K_n（n ＝ 1〜4、q ＝ 0, 1/3, 9/10, 1）の包囲、4点で g・g_rr・g_ss を mpmath の高精度値と照合 → すべて区間内。
- 較正の4小箱（内側 32×32）：赤道 τ ∈ [1/32, 1/16]、λ ∈ [2/5, 41/100] で ＋0.320461（Dig の producer は ＋0.265447）、τ ∈ [0, 1/32] で ＋0.321470、中央 ＋0.544533（Dig ＋0.448407）、極 ＋0.626424（Dig ＋0.631112）。浮動小数で測った真の値は赤道で約 0.397。
- 点に縮めた外箱：τ ＝ 0、λ ＝ 2/5 で下界 0.392511（中点の和/π 0.397181、真値 0.3971015250）。τ ＝ 1/2、λ ＝ 1/2 で 0.807878（中点の和/π 0.819361、真値 0.8192194812）。下界は真値より下で、中点の和は真値とほぼ一致。
- `cal12_out.jsonl`・`pts_out.jsonl` は高速化前の版（K_n を冪の厳密計算・項数60固定で評価）の出力。`reg_out.jsonl` は同梱の現行版の出力で、同じ箱の厳密な下端の差は約 2.5×10⁻¹⁶（p の格子 2^−48 による）。
