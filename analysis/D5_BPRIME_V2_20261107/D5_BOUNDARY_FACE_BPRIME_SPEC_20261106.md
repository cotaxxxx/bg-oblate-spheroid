## 0. 目標

**定理（面の下界）：** τ ∈ [0, 1]、λ ∈ [2/5, 33/50] のすべてで、外側の面の点 L_λQ(τ) において H ≥ m_∂ が成り立つ。

- Q(τ) ＝ (a(τ), 0, b(τ))、a ＝ (1−τ²)/(1+τ²)、b ＝ 2τ/(1+τ²) とする。
- **目標値は m_∂ ＝ 1/4。** 較正の結果によっては 1/5 に下げることもあるが、その判断は被覆を固定する前に行う。
- 浮動小数で測った真の値（証明の入力にはしない）：最小は赤道（τ ＝ 0）付近の約 0.397（λ ＝ 0.4）で、極に向かって 1.15 まで大きくなる。

- B7 の本走には触れない。commit／push はしない。

## 1. 使う式（chat が確かめた）

Codex の診断書 §4.1 の (B0) を使う。

H ＝ (1/π) ∫_{−1}^{1} ∫_0^{π} f(μ, φ) dφ dμ、f ＝ ∫_0^1 P dt、P ＝ γF/(KA²)

**t についての積分は、閉じた形に直す。** A ＝ 1 ＋ t² ＋ (1−t²)γ、c ＝ 1 − t² とすると F ＝ A·α ＋ γc·β となるので、

f ＝ (γ/(2K))·[α·R(γ) − γβ·R′(γ)]
- α ＝ 1 − n − 2n(1−2K)²
- β ＝ n(1−2K)²
- R(γ) ＝ 2∫₀¹ dt/A
- R′(γ) ＝ −2∫₀¹ c/A² dt

**幾何：**
- ξ ＝ (√(1−μ²)cos φ, √(1−μ²) sin φ, μ)
- σ ＝ |ξ − Q|、ν ＝ (ξ − Q)/σ
- K ＝ ν_x² ＋ ν_y² ＋ λ²ν_z²、n ＝ ν_y²/K
- w² ＝ λ² ＋ (1−λ²)μ²
- γ ＝ λσ/(2wk)、k ＝ √K

**chat の数値照合：**
- (B0) の正規化：面の内側の点で H(r) を直接計算し、r ＝ 0.9、0.97、0.99、0.997 で 0.991、0.875、0.838、0.825 となった。これは面の上の (B0) の値 0.8192 に収束する（λ ＝ 1/2、τ ＝ 1/2）。
- t を閉じた形に直した式：t についての数値積分と15桁一致した（3点）。

## 2. 区間で評価するときの構成（M40 の verifier と同じ道具）

1. **半角の置換：**
   - μ ＝ ±(1−u²)/(1+u²)、√(1−μ²) ＝ 2u/(1+u²)、|dμ| ＝ 4u/(1+u²)² du（u ∈ [0, 1]）
   - φ ∈ [0, π/2] は s ＝ tan(φ/2) ∈ [0, 1] と置き、cos φ ＝ (1−s²)/(1+s²)、sin φ ＝ 2s/(1+s²)、dφ ＝ 2ds/(1+s²)
   - φ ∈ [π/2, π] は cos の符号を反転する。
   - これで枝は4本（μ の符号 × cos φ の符号）になる。
2. **σ² は差を取らずに計算する：** |ξ|² ＝ |Q|² ＝ 1 なので、σ² ＝ 2 − 2ξ·Q ＝ 2(1 − a·ξ_x − b·μ)。
3. **R と R′ の包囲：** q ＝ (1−γ)/(1+γ)、a₀ ＝ 1 ＋ γ とすると、A ＝ a₀(1 ＋ q t²) となる。そこで
   - R^(m)(γ) ＝ 2(−1)^m m!·a₀^(−(m+1))·K_{m+1}(q)、K_n(q) ＝ ∫₀¹ (1−t²)^(n−1)(1 ＋ q t²)^(−n) dt
   - K_n(q) は q について単調減少なので、級数と符号つきの剰余で包める（`chat_m40iv.Kn` と同じ）。
   - 角度についての Taylor 係数（2次まで）を作るために、γ ＝ γ₀ ＋ Δ と展開する。必要な R^(m) は m ≤ 3（R′ と、その2階まで）。
4. **中点線版の中点則：** セルごとに |C|·[f(m) ＋ h_u²/24·inf_C f_uu ＋ h_s²/24·inf_{u＝m_u の線} f_ss]。f にはヤコビアン 4u/(1+u²)²·2/(1+s²) を含め、そのうえで微分する。
5. **接触点の周りの切り取り：** 外箱の中の Q について、セル上の σ の下限が σ_c 未満になるセル（σ_c は較正で決める。目安は 1/16）は、中点則を使わずに次の下界で置き換える。
   - |f| ≤ (γ/(2K))·(|α|R ＋ γ|β||R′|)
   - 各因子の上界：γ ≤ σ/(2λ)、K ≥ λ²、R ≤ π/2 ≤ 355/226、|R′| ≤ 1（A ≥ 1 ＋ t² から）、|α| ≤ 3、|β| ≤ 1
   - まとめると |f| ≤ σ·(3·355/226 ＋ 1)/(4λ³)
   - **cut したセルの寄与** ≥ −(セルの測度)·(3·355/226 ＋ 1)·σ_hi/(4λ_lo³)
   - 損失の目安は σ_c³ の程度で、σ_c ＝ 1/16 なら約 0.006。
6. **前因子：** 1/π は 113/355 ≤ 1/π ≤ 106/333 で挟み、符号を見て掛ける。
7. **幾何的な切り詰め：**
   - γ ∈ [0, 1]
   - K ∈ [λ_lo², 1]
   - n ∈ [0, 1]
   - w ∈ [λ_lo, 1]
   - σ ∈ [0, 2]

## 3. 較正（被覆を固定する前に1回だけ）

1. 外箱を、τ の幅 1/16 × λ の幅 1/50 程度の大きさにして、次の3箱で試す。内側の格子を2通り（M40 と同じ不均一な格子と、32×32）、σ_c を2通り（1/16 と 1/32）試し、下界と時間を測る。
   - 赤道（τ ∈ [0, 1/16]、λ の下端）
   - 中央（τ ≈ 1/2）
   - 極（τ ∈ [15/16, 1]）
2. 結果をもとに外箱の分け方を決め、被覆ファイルを作って SHA とともに chat に渡す。**chat が被覆の検査を通してから、本走に入る。**
3. 点での照合：外箱を1点に縮めたときの下界が、§1 の真の値（たとえば λ ＝ 0.4、τ ＝ 0 で 0.3971）以下で、細かくすると近づいていくことを確かめる。
