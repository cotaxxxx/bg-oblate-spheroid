## 1. 式との対応（依頼書 §2-1）

- Q(τ) = (a, 0, b)、a = (1−τ²)/(1+τ²)、b = 2τ/(1+τ²) の実装は仕様どおり。
- ν = −sin(ψ/2)·Q + cos(ψ/2)·e(θ) の3成分、ξ_z = b cos ψ + a cos θ sin ψ、
  σ = 2 sin(ψ/2) = 4r/(1+r²)、いずれも v2 差分 §1 の式と一致する。σ での除算は
  コードのどこにも現れない（接触点で正則）。
- K は成分形 ν_x²+ν_y²+λ²ν_z² と恒等な 1 − ν_z²(1−λ²) で計算される
  （|ν|² = Sh² + Ch² = 1 はパラメータ表示の恒等式として成立）。
- α = 1 − n − 2n(1−2K)²、β = n(1−2K)²、f = (γ/(2K))[αR − γβR′] は仕様 §1 と一致。
- ヤコビアン：g = f·sin ψ·4/(1+r²)·2/(1+s²) は dψ = 4dr/(1+r²)、dθ = 2ds/(1+s²)
  と面積要素 sin ψ dψ dθ から正しく出る。
- y 対称性：f は ξ_y の符号に依存しない（ν_y²、ξ_z、σ のみを通る）ため
  θ ∈ [0, π] への制限と前因子 1/π の組は (B0) 形の正規化と一致する（§8 で数値的に固定）。
- 枝 eps：eps=+1 が θ ∈ [0, π/2]、eps=−1 が cos θ の符号反転による θ ∈ [π/2, π] を覆い、
  重なりは測度 0 の θ = π/2 のみ、sin θ ≥ 0 と |dθ/ds| は両枝で共通。過不足はない。

## 2. K_n の包囲（依頼書 §2-2、新規部分）

- 級数の導出を確認した。(1+qt²) = (1+t²)(1 − p·t²/(1+t²))（p = 1−q）より
  (1+qt²)^(−n) = (1+t²)^(−n) Σ_k C(n+k−1, k)(p t²/(1+t²))^k。全項非負、pu ≤ 1/2 で収束。
- 項の積分 M(n,k) の置換 t = tan θ による ∫₀^{π/4} cos^{n−1}(2θ) sin^{2k}θ dθ への
  変形は指数の計算まで含めて正確だった。さらに φ = 2θ と置くコードの形
  (1/2)∫₀^{π/2} c^{n−1}((1−c)/2)^k dφ とも一致し、Wallis 積分の有理数＋有理数×π の
  厳密値（π は検証済みの区間 [103993/33102, 104348/33215]）で評価されている。
- 剰余：M(n,k) ≤ (1/2)^k M(n,0)（t²/(1+t²) ≤ 1/2）と比 (n+k)/(k+1)·(p/2) の
  級数評価は正しい。項数 N は float で選ばれるが、使用される剰余は選ばれた N に
  対して有理数で厳密に計算され、rho < 1 は Fraction の assert で fail-closed。
- q → p の変換は 2^−48 格子への外向き丸め＋[0,1] へのクランプで、K_n の
  q についての単調減少性による端点評価（pa で下端、pb で上端）も正しい。
- 数値照合（mpmath 60 桁）：M(n,k) 24 件、Kn_point 32 件、Kn（区間）16 件、
  すべて直接数値積分を区間内に含んだ（p = 0, 1 の端点を含む）。

## 3. R∘γ の Taylor 合成（依頼書 §2-3）

- γ = γ₀ + D（D は冪零部分、DB=2 の打ち切りで D³ = 0）として
  R(γ₀) + R′(γ₀)D + R″(γ₀)D²/2、R′ 側は R‴ まで使う合成は正しい。
- Rderivs は γ₀ 区間の端点から q 区間を作り、R^(m) を区間全体で包む。
  mpmath による照合：閉形式 R(γ) = arccos γ/√(1−γ²) の微分、および定義積分
  R = 2∫dt/A、R′ = −2∫(1−t²)/A² とも一致し、m = 0..3 の 5 区間すべてで
  サンプル点の範囲を区間内に含んだ。

## 4. 切り詰め cap0 と γ ≤ 1（依頼書 §2-4）

- cap0 は J の定数係数のみに作用する（監査済みの流用）。各切り詰め範囲は真の範囲を
  含むことを個別に確認した：sin(ψ/2) = 2r/(1+r²) ∈ [0,1]（(1−r)² ≥ 0）、
  sin θ ∈ [0,1]、K ∈ [λ_lo², 1]、n = ν_y²/K ∈ [0,1]（K − ν_y² = ν_x² + λ²ν_z² ≥ 0）、
  w ∈ [λ_lo, 1]（w² = λ² + (1−λ²)ξ_z²、ξ_z² ≤ 1）。
- **γ ≤ 1 の厳密証明を監査側で構成した。** X = sin²(ψ/2)、Y = cos²θ、Z = a²、
  W = sin(ψ/2)cos(ψ/2)cos θ·a·b（W² = X(1−X)YZ(1−Z)）と置くと
  4w²K − λ²σ² = 4[A₀ + B₀W] と書ける（記号計算と直接数値の照合済み）。
  さらに有理パラメータ表示 (r, s, τ, λ²) では、1 − γ² の分子 NN は s の偶関数で、
  **NN|_{s=0} = 4Φ²（完全平方）**、**NN|_{r=1} = 1024 τ²(1−λ²)²(1+s²)⁴(τ−1)²(τ+1)²**
  と因数分解される（両 eps 枝）。前者は chat の報告する子午線上の等号（γ = 1 の
  内点）の機構そのもので、後者は対蹠点での等号が τ ∈ {0, 1} のみに限ることを示す。
  さらに、次の閉じた恒等式で γ ≤ 1 を完全に証明した。ξ = (x, y, z)（単位球上）、
  Q = (a, 0, b)、a² + b² = 1、σ² = 2 − 2(ax + bz)、Kσ² = (x−a)² + y² + λ²(z−b)²、
  w² = λ² + (1−λ²)z² とすると、

    σ²(4w²K − λ²σ²)/4
      = y²·[λ²a² + (1−λ²)²(z + λ²b/(1−λ²))²] + [λ²bx − z(a − (1−λ²)x)]²

  が a² + b² = 1 と x² + y² + z² = 1 のもとで恒等的に成り立つ（記号計算で検証、
  数値照合 20,000 点で誤差 1.3e-15 以内）。右辺は λ ∈ (0, 1) で明らかに ≥ 0 であり、
  σ > 0 のとき γ² = λ²σ²/(4w²K) ≤ 1、σ = 0 のとき γ = 0。等号は両平方項が
  同時に消えるときで、主成分は子午面 y = 0 上の曲線 λ²bx = z(a − (1−λ²)x)
  （(r, τ) 座標での Φ = 0）である。よって cap0 の γ ∈ [0, 1] は正当であり、
  γ = 1 の点でも q = 0 として K_n 級数の範囲内にある（§2 で p = 1 まで照合済み）。
  副産物として、(X, Y, Z) 座標では A₀|_{X=0} = (1 − Z(1−λ²))(1 − YZ(1−λ²))（正）、
  A₀|_{X=1} = (1−λ²)²Z(1−Z) の因数分解も得られている。

## 5. 中点線版の中点則（依頼書 §2-5）

- 逐次形の規則 ∫∫_C g ≥ |C|[g(m) + h_r²/24·inf_C g_rr + h_s²/24·inf_{r=m_r} g_ss] は、
  r 方向に中点則（Peano 核による誤差の下限評価）を先に適用し、残りを s 方向に
  適用することで得られ、正しい。
- `box_lower` の実装はこの形と正確に対応する：値の項はセル中点の点区間、
  曲率項 cr は R・S ともセル全体の区間（inf_C g_rr）、cs は R を中点に固定し
  S をセル全体とした直線上の評価（inf_{r=m_r} g_ss）、係数はいずれも |C|·h²/24。
- 2階微分の jet 値（c[(0,2)]×2）は §1 の照合で mpmath の2階微分と一致した。
- 中点部分と曲率部分の下端は `mid_lo_raw`・`curv_lo_raw` として別々に記録され、
  v2 差分 §2 の報告要件（中心値ではなく下端）を満たす。
